# 内省の問いカード（COACHING-L）

コーチング事業「COACHING-L」のブログからリンクする、内省用の「問いカード」アプリです。
カードをタップすると、コーチングで使う「人生の輪」の8つの領域から問いがランダムに1つ出ます。出てきた問いをきっかけに、自分の考えを深めてください。

- HTML・CSS・JavaScript だけで動きます（ビルド不要、外部ライブラリなし）
- 入力内容の保存・送信、アクセス解析、Cookie は一切使っていません
- スマホ優先のレイアウトで、PC・タブレットでも使えます（iPhone の Safari、Chrome、Edge に対応）

## 主な機能

- 「すべて」と8つのカテゴリから、引く問いの範囲を選べます（最初は「すべて」）
- カードは最初は裏向きです。タップ（または Enter／スペースキー）でめくると、問いが表示されます
- 「次のカード」で、選んだカテゴリから次の問いをランダムに出します。山札をシャッフルする方式なので、すべて出し切るまで同じ問いは出ません。最後の1問を引くと「このカテゴリの問いを、ひと通り引きました。」（「すべて」のときは「すべての問いを、ひと通り引きました。」）と知らせ、もう一度「次のカード」を押すと、最初から引き直せます
- 「次のカード」ボタンの下に「答えにくい問いは、無理に考えずに次へ進んで大丈夫です。」と表示し、1問ずつ無理なく向き合えるようにしています
- 端末の「視差効果を減らす」（動きを減らす）設定がオンの場合は、めくるアニメーションをしません
- 端末の表示設定（ライト／ダーク）に合わせて、自動で配色が切り替わります

## デザイン

- 配色・ロゴ・ファビコンは、COACHING-L のポモドーロタイマー（coaching-l/pomodoro）とそろえています
  - ライト：背景 #f7f8fa、紺 #042143、金 #c09e5c
  - ダーク：背景 #02172f、ボタンや選んだ項目は金 #c09e5c
- カテゴリごとの色（`questions.json` の `color`）は、ブログの「人生の輪」ツールとそろえています

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `style.css` | デザイン（色・レイアウト・カードのアニメーション） |
| `app.js` | 動き（カテゴリの切り替え、山札、カードをめくる処理） |
| `questions.json` | カテゴリと問いのデータ |
| `icons/` | ロゴとファビコン（ポモドーロタイマーと同じ画像） |

`style.css` や `app.js` を変えたときは、`index.html` の中の `style.css?v=2`・`app.js?v=2` の数字を1つ上げてください。ブラウザに古いファイルが残って、表示が崩れるのを防ぐためです（`questions.json` だけを変えたときは不要です）。

## 公開URLの形式

GitHub Pages（main ブランチのルート）で公開します。

```
https://coaching-l.github.io/reflection-cards/
```

URL の末尾に `?cat=カテゴリID` を付けると、そのカテゴリが選ばれた状態で始まります。
「人生の輪」で気になった領域（変化を起こす準備ができている領域）から、直接リンクするときに使えます。

```
https://coaching-l.github.io/reflection-cards/?cat=money
```

### `?cat=` で使えるカテゴリID

| カテゴリID | カテゴリ名 |
| --- | --- |
| `health` | 心身の健康 |
| `career` | 仕事・キャリア |
| `growth` | 自己成長 |
| `play` | 遊び・余暇 |
| `relationships` | 人間関係 |
| `environment` | 物理的環境 |
| `family` | 家族・パートナー |
| `money` | お金・財務 |

存在しないIDを指定した場合や、`?cat=` を付けない場合は「すべて」で始まります。

## questions.json に問いを追加する方法

`questions.json` の中で、追加したいカテゴリの `"questions"` の一覧に、問いを1行足します。

```json
{
  "id": "money",
  "name": "お金・財務",
  "color": "#C06C99",
  "questions": [
    "お金について考えるとき、最初に浮かぶ気持ちは何ですか？",
    "お金との付き合い方で「いいな」と思うのは、どんな人ですか？その人のどんなところを取り入れたいですか？",
    "ここに新しい問いを追加します"
  ]
}
```

注意点：

- 問いは `"` （半角のダブルクォーテーション）で囲みます
- 問いと問いの間は `,` （半角のカンマ）で区切ります。**最後の問いのあとにはカンマを付けません**
- 保存して GitHub に反映すれば、アプリに自動で反映されます（アプリ側の修正は不要です）
- 書式が崩れると問いを読み込めなくなるため、心配なときは JSON チェックツールなどで確認してください

カテゴリそのものを増やす場合は、`categories` の一覧に `id`（URL で使う半角英字）、`name`（表示名）、`color`（色）、`questions`（問いの一覧）をそろえて追加します。

## 手元のパソコンで確認する方法

`index.html` をファイルとして直接開くと、ブラウザの制限で `questions.json` を読み込めません。
次のように簡易サーバーを起動して、`http://localhost:8000/` を開いてください。

```
python3 -m http.server 8000
```
